
# Mini Portal de Colombia 🇨🇴

## Descripción

Mini Portal de Colombia es un sitio web informativo que permite
conocer los departamentos y la gastronomía típica del país.

El proyecto utiliza una API pública para obtener información
y mostrarla dinámicamente en el navegador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- API Colombia

## Funcionalidades

- Explorador de departamentos.
- Información sobre población y superficie.
- Identificación de regiones.
- Catálogo de platos típicos.
- Visualización de imágenes.
- Conteo de departamentos, regiones y platos.
- Navegación entre páginas.

## Instrucciones de uso

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar la extensión Live Server.
4. Abrir index.html con Live Server.
5. Navegar entre las páginas utilizando el menú.
